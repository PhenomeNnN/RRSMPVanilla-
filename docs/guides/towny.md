# Towny: города, участки и нации

Towny защищает городскую территорию и помогает жителям объединяться. **Город** состоит из участков, **мэр** управляет городом, а **нация** объединяет города.

Городской участок занимает чанк **16×16 блоков по всей высоте мира**. Граница участка совпадает с границей чанка: на Java Edition её можно показать через `F3+G`.

## Вступить в город

1. Открой `/t list` и найди подходящий город.
2. Посмотри `/t ГОРОД`: проверь жителей, налог и PvP. Узнай у мэра условия поселения.
3. Для открытого города введи `/t join ГОРОД`. Для закрытого попроси мэра пригласить тебя через `/t add НИК` и подтверди приглашение `/accept`.
4. Попроси выделить участок. Если он выставлен на продажу, встань внутри и введи `/plot claim`.
5. Проверь `/plot perm` и `/res` перед переносом ценных вещей.

Вступление в город не выдаёт автоматически личный участок. Городская земля и участок конкретного жителя имеют свои настройки доступа.

## Основать свой город

Выбери место в обычном мире вне чужих городов и запрещённых регионов. Встань в будущий центральный чанк и введи `/t new НАЗВАНИЕ`. Проверь результат через `/t`.

После основания:

1. Пополни городской банк через `/t deposit СУММА`: личный кошелёк не заменяет городской счёт.
2. Присоединяй соседние чанки командой `/t claim`, стоя в нужном чанке.
3. Подготовь безопасное место и установи `/t set spawn` в домашнем участке.
4. Пригласи жителей через `/t add НИК`.
5. Проверь PvP, публичность, вступление и налоги. Сообщи условия будущим жителям.

## Деньги и содержание

| Действие | Подготовленный профиль |
| --- | --- |
| Основание города | 250 |
| Основание нации | 1000 |
| Содержание города | 10 за сутки Towny |
| Содержание нации | 100 за сутки Towny |
| Обычный новый чанк | 25 |
| Аванпост | 500 |
| Базовый лимит земли | 8 участков на жителя, плюс действующие бонусы |
| Налог жителей нового города | 0; дальше определяет мэр |

Актуальные цены проверь `/towny prices`, ближайшее списание — `/towny time`. Сутки Towny — расчётный период плагина; не считай моментом списания полночь по МСК.

!!! warning "Держи резерв в банке"
    Содержание включено, банкротство отключено. Недостаток денег может привести к потере города или нации. Налог жителей и содержание города — разные платежи.

Мэр задаёт налог через `/t set taxes СУММА`. Прежде чем менять значение, проверь, используется фиксированная сумма или процентный режим. В подготовленном профиле предел процентного налога — 25%.

## Участки и доступ

Мэр выставляет городской участок через `/plot forsale ЦЕНА`; житель покупает его через `/plot claim`. Для отмены продажи есть `/plot notforsale`.

Towny различает строительство, разрушение, переключатели и использование защищённых предметов. Допуски задаются для групп, например жителей, союзников и посторонних. Проверяй `/plot perm` на каждом участке с отдельными настройками.

Чтобы закрыть посторонним доступ на своём участке, используй `/plot set perm outsider off`. Не включай общий доступ всем ради одного гостя. После изменения проверь сундук, дверь и строительство с обычным игроком без административных прав.

В дикой местности профилем разрешены обычные действия, кроме отдельных защищённых регионов. Строительство за границей города не получает городскую защиту автоматически. Снятие городского привата не восстанавливает ландшафт: постройки остаются без прежней защиты.

## PvP

В новых городах PvP включён. Мэр переключает его через `/t toggle pvp`, после чего проверяет `/t`. Защита блоков сама по себе не означает безопасную зону для боя.

Мировые настройки и особые участки могут влиять на бой дополнительно. Техническая возможность нанести урон не заменяет [правила поведения](../rules.md).

## Телепорты

| Назначение | Цена по профилю |
| --- | --- |
| Свой город: `/t spawn` | 0 |
| Город своей нации | 5 |
| Доступный союзный или публичный город | 10 |

Для чужого города используется `/t spawn ГОРОД`. Доступ зависит от публичности и отношений. Ожидание — 5 секунд; движение или урон отменяют перенос. Перезарядка — 30 секунд в соответствующей категории Towny. Межмировые телепорты запрещены.

## Нации

Лидер города может создать нацию через `/n new НАЗВАНИЕ`, если выполнены требования. Приглашение другого города — `/n add ГОРОД`, просмотр своей нации — `/n`, пополнение банка — `/n deposit СУММА`.

Обсуди с мэрами налоги, общий банк и обязанности. Создание нации само по себе не означает наличие осад или войн: такие механики требуют отдельных систем и объявлений.

## Что запомнить

- Перед заселением узнай налог и режим PvP.
- Перед стройкой проверь, внутри ли ты города и своего участка.
- Перед списанием проверь банк и `/towny time`.
- Перед выходом из города согласуй судьбу дома и вещей.
