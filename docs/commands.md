# Справочник команд

`НИК`, `ГОРОД`, `СУММА` и другие слова заглавными буквами заменяй своими значениями, без скобок. Команды вводятся в игровой чат после авторизации. Доступ зависит от роли, прав и установленных настроек сервера.

## Вход и помощь

| Команда | Действие |
| --- | --- |
| `/register ПАРОЛЬ ПАРОЛЬ` | Создать аккаунт; повторить пароль дважды |
| `/login ПАРОЛЬ` | Войти в аккаунт |
| `/changepassword СТАРЫЙ НОВЫЙ` | Сменить пароль |
| `/captcha КОД` | Ответить на проверку, если она появилась |
| `/menu` | Открыть главное меню |
| `/rules` | Прочитать правила в игре |
| `/help` | Доступная справка |
| `/motd` | Информация сервера |
| `/helpop ТЕКСТ` | Обратиться к сотрудникам онлайн |

Не сокращай `/login` до `/l`: в подготовленном CarbonChat `/l` используется локальным чатом.

## Чат и общение

| Команда | Действие |
| --- | --- |
| `/msg НИК ТЕКСТ` | Личное сообщение |
| `/ignore НИК` | Управление игнорированием игрока |
| `/g` | Переключиться в общий чат |
| `!ТЕКСТ` | Разовое сообщение в общий чат |
| `/lc` | Переключиться в локальный чат, радиус 100 блоков в одном мире |
| `/tc` | Городской канал |
| `/nc` | Канал нации |
| `/ac` | Канал союзников |
| `/party` | Справка и управление отрядом ValhallaMMO |
| `/party info` | Информация об отряде |
| `/partychat ТЕКСТ` | Сообщение отряду |

Каналы `/g`, `/lc`, `/tc`, `/nc`, `/ac` описывают подготовленный профиль CarbonChat. Для городских каналов требуется соответствующее членство. Между сообщениями одного канала предусмотрена пауза 2 секунды.

## Towny: жителю

`/t` — сокращение `/town`, `/n` — `/nation`, `/res` — `/resident`.

| Команда | Действие |
| --- | --- |
| `/towny` | Общая справка Towny |
| `/towny map` | Карта ближайших городских участков в чате |
| `/towny prices` | Текущие цены Towny |
| `/towny time` | Время до следующего ежедневного расчёта |
| `/t list` | Список городов |
| `/t ГОРОД` | Информация о городе |
| `/t` | Информация о своём городе |
| `/res` | Информация о себе и участках |
| `/t join ГОРОД` | Вступить в открытый город |
| `/accept` / `/deny` | Принять / отклонить полученное приглашение |
| `/t leave` | Выйти из города — сначала согласуй судьбу своего участка |
| `/t deposit СУММА` | Внести деньги в банк города |
| `/t spawn` | Телепорт в свой город |
| `/t spawn ГОРОД` | Телепорт в доступный город; может быть платным |
| `/plot claim` | Купить выставленный участок, стоя внутри него |
| `/plot perm` | Посмотреть права текущего участка |
| `/plot set perm outsider off` | Закрыть посторонним доступ на принадлежащем тебе участке |

## Towny: мэру и лидеру нации

| Команда | Действие |
| --- | --- |
| `/t new НАЗВАНИЕ` | Создать город в текущем чанке |
| `/t claim` | Присоединить соседний чанк за деньги города |
| `/t add НИК` | Пригласить жителя |
| `/t set spawn` | Установить точку телепорта в домашнем участке |
| `/t toggle open` | Переключить свободное вступление |
| `/t toggle public` | Переключить публичность города |
| `/t toggle pvp` | Переключить городской PvP |
| `/t set taxes СУММА` | Настроить налог жителей; проверь режим налога |
| `/plot forsale ЦЕНА` | Выставить городской участок на продажу |
| `/plot notforsale` | Снять участок с продажи |
| `/n new НАЗВАНИЕ` | Создать нацию при выполнении требований |
| `/n` | Информация о своей нации |
| `/n add ГОРОД` | Пригласить город в нацию |
| `/n deposit СУММА` | Пополнить банк нации |

!!! warning "Проверяй настройки после переключения"
    `toggle` меняет текущее состояние на противоположное. Повторный ввод отменяет первое изменение. После команды открой `/t` и проверь результат.

## Деньги, торговля и другие системы

| Команда | Действие |
| --- | --- |
| `/balance` | Проверить кошелёк |
| `/pay НИК СУММА` | Перевести деньги игроку; проверь ник и сумму |
| `/vault:balance` | Явно открыть баланс через Vault при конфликте команд |
| `/vault:pay НИК СУММА` | Явно выполнить перевод через Vault |
| `/qs` | Справка QuickShop; торговля и управление также используют клики |
| `/graves` | Посмотреть свои могилы |
| `/brew help` | Справка BreweryX |

Этот список предназначен игрокам. Команды редакторов, модерации, импорта контента и управления плагинами сюда не включены. Наличие команды в документации плагина не гарантирует её доступность на сервере.
